# Advanced Gallery Block

A WordPress Gutenberg block for creating responsive image galleries with lightbox functionality.

## Features

- Responsive grid layout with customizable columns for desktop, tablet, and mobile
- Built-in lightbox with keyboard navigation
- Lazy loading support
- Customizable gap, border radius, and hover effects
- Clean, modular code structure

## Installation

1. Upload the plugin files to `/wp-content/plugins/advanced-gallery-block/`
2. Activate the plugin through the WordPress admin panel
3. Add the Advanced Gallery block in the Gutenberg editor

## Usage

1. In the WordPress editor, add a new block
2. Search for "Advanced Gallery"
3. Select images from your media library
4. Configure responsive settings, lightbox, and styling options

## Requirements

- WordPress 5.0+
- PHP 7.4+
